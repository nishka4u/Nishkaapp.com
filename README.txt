NISHKA WEBSITE
================
Files:
- index.html
- businesses.html
- homemakers.html
- about.html
- style.css
- script.js

DEPLOY TO NETLIFY
1. Keep all files in the same folder.
2. Drag the nishka folder (or ZIP contents) into Netlify's deploy area.
3. The site will use index.html as the homepage.

FORMS
The forms are configured to POST to the Google Apps Script endpoint supplied in the project.
The script uses no-cors, so the browser cannot read a server response. The success message means the request was sent; verify your Apps Script/Sheet setup after the first submission.

IMPORTANT
Replace placeholder contact details with real Nishka details before launch.
Review Privacy Policy and Terms & Conditions before public launch.
